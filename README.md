# 国学老师 H5

一个以国学咨询为主题的移动端 H5 MVP。项目使用原生 HTML、CSS 和 JavaScript 实现，重点验证本地模拟登录、八字档案与 AI 老师咨询的完整流程。

> 当前版本是纯前端演示：回答由本地关键词规则生成，不会请求 AI 或后端服务；档案和会话数据仅保存在当前浏览器中。

## 功能概览

- 国风移动端首页与按本地日期自动更新的“今日指引”
- 手机号与演示验证码 `123456` 的本地登录流程，以及未登录、无档案、可咨询三种首页状态
- 专业排盘宫格内的万年历入口，支持公历月视图、农历日期、月份切换与快速返回今天
- 首页提交首条问题后进入独立对话页，并展示约 700 ms 的模拟回复状态
- 不限次数的免费模拟对话
- 对话额度状态与“限时免费”运营标签独立配置和渲染
- 按日期保存和切换历史会话
- 独立的“我的档案”页面，支持新增、编辑、删除及切换八字档案
- 档案出生地支持省、市、区三级联动，也可选择“海外”
- “国心解读”直接进入绑定当前档案的空白 AI 对话，不预设问题、不自动发送
- 个人中心抽屉保留档案与对话记录；报告入口及生成、查看、购买流程在 MVP 中停用
- 个人资料与设置支持本地昵称、昵称首字头像、全站字号偏好和客服微信模拟入口
- 中文输入法组合态处理、焦点管理和减少动态效果适配
- `src/pages/chat.html` 提供独立对话界面，首页提问和历史会话均跳转至该页面

“专业排盘”与“学习资料”等既有演示入口保持不变。报告页面、存储和底层接口仍保留以便未来恢复完整版，但 MVP 路由不会进入这些流程。

## 快速开始

项目没有依赖安装和编译步骤。建议通过本地 HTTP 服务访问，避免直接打开文件时出现浏览器存储或资源加载限制。

使用 Python：

```bash
python -m http.server 8000
```

或使用 Node.js：

```bash
npx serve .
```

然后访问 `http://localhost:8000/src/pages/index.html`（`serve` 输出的端口可能不同）。

## 项目结构

```text
.
├── src/
│   ├── pages/              # 首页、档案页和旧入口兼容页
│   │                       # 以及报告、排盘和微信模拟页面
│   ├── js/                 # 页面逻辑、共享状态、本地数据 API 和排盘配置
│   ├── css/                # 全站样式、排盘样式、响应式布局和动效
│   └── components/         # 后续可复用的公共组件
├── public/
│   ├── images/             # 国风插画、头像和功能图片
│   ├── data/               # 省市区数据及第三方许可说明
│   ├── icons/              # 独立图标资源
│   └── fonts/              # 本地字体资源
├── docs/                   # 设计和 API 文档
└── test-output/            # 本地测试生成物，不提交到 Git
```

需要读取档案、会话、额度或报告状态的页面，应先加载 `shared.js`，再加载对应的页面脚本。共享状态以 `window.GuoxueApp` 暴露；专业排盘页面改为先加载 `chart-methods.js`，再加载列表或表单脚本。

对话额度由 `getQuota()` / `consumeQuota()` 单独提供，当前始终返回无限状态；右上角“限时免费”是独立的运营标签，由 `getPromotionBadge()` / `renderPromotionBadge()` 提供，不读取或展示额度数据。

## 数据与限制

登录、档案和会话等状态均写入 `localStorage`。登录状态使用 `guoxueCurrentUserV1`；退出登录只清除该键，不删除档案、会话、报告或偏好。不同手机号共享当前浏览器中的本地演示数据。

| 数据 | 限制 |
| --- | ---: |
| 对话次数 | 无限制 |
| 单个会话消息 | 40 条 |
| 历史会话 | 90 个 |
| 八字档案 | 20 份 |
| 国心解读报告 | 30 份 |

当 `localStorage` 不可用时，应用会退回到当前页面生命周期内的内存存储。清除站点数据、使用另一台设备或更换浏览器后，已有数据不会保留。

个人昵称和字体大小保存在 `guoxueUserPreferencesV1`，头像自动使用昵称首字。字号提供小、标准、大三档，并在各页面加载样式前恢复，避免跳转时闪回默认字号。

八字档案目前只负责保存用户填写的信息，不会自动换算公历/农历，也不会生成排盘结果。

档案出生地选项由 `public/data/china-regions.json` 提供；数据加载失败时仍可读取已有档案中的出生地文本，但当前表单不会提供手工输入替代项。数据来源与许可见 `public/data/README.md`。

国心解读报告绑定生成时的档案快照。修改档案后会形成新的报告版本，旧报告及其解锁权益仍保留；相同快照重复进入时会复用已有报告。完整报告模拟价格为 ¥88，单章为 ¥16.8，已购单章金额可抵扣完整报告。

## 开发说明

- 页面语言为简体中文，源文件统一使用 UTF-8。
- 视觉尺寸以移动端设计稿为主，并通过 CSS 自定义属性和媒体查询适配屏幕。
- 新增交互时优先延续 `data-action`、事件委托和 `pressable` 状态约定。
- 修改持久化结构时，应同步更新版本、标准化逻辑和旧数据迁移。
- 不要将真实密钥、敏感出生信息或生产数据写入仓库。

项目暂未配置自动化测试。提交前至少手动检查：

1. 首页在窄屏和桌面浏览器中均可正常显示。
2. 中文输入法按 Enter 不会在组合输入过程中误发送。
3. 可连续发送问题、显示回复，并可从历史会话恢复。
4. 抽屉可通过菜单、遮罩、Esc 和边缘滑动打开或关闭。
5. 八字档案可新增、编辑、切换和删除，非法日期会被拦截。
6. 刷新页面后，本地会话和档案仍然存在。
7. 国心解读在登录且有档案时直接进入空白对话，发送问题后回复包含当前绑定档案摘要。
8. 专业排盘宫格内的万年历入口可正常跳转，切换月份、选择日期和返回今天均可用。

项目当前不做线上部署，仅在本机预览。按上文「快速开始」启动静态服务器后，访问 `src/pages/index.html` 即可。

## 隐私提示

出生日期、时间和地点属于个人信息。当前实现只在浏览器本地保存这些内容，但正式上线前仍应补充清晰的隐私说明、数据删除机制、安全评审和必要的合规措施。

### 对话图片附件

- 首页、普通对话和报告章节对话均支持上传一张 JPG、PNG 或 WebP 图片，单张不超过 10MB。
- 图片文件仅保存在当前浏览器的 IndexedDB `guoxueImageAttachmentsV1` 中，不会上传到外部服务；会话记录只在 `attachments` 字段保存附件 ID、文件名、MIME 类型、大小和图片尺寸。
- `attachments` 为可选数组，旧版纯文字消息无需迁移即可继续读取。纯图片消息的会话标题为“图片咨询”。
- 当前为前端演示，老师回复只确认已收到图片，不进行真实图片识别。
