# 设计说明

项目采用移动端国风视觉语言，页面结构集中在 `src/pages/`，共享样式位于 `src/css/styles.css`，运行时图片位于 `public/images/`。

当前首页同时承载今日指引、功能入口、问答区和个人中心抽屉；档案表单位于独立页面。后续抽取公共组件时，应保持原生 HTML/CSS/JavaScript、无构建步骤和现有无障碍行为。

## 国心解读

国心解读采用“老师陪读式”结构：用户先选择八字档案，由国学老师给出免费总览和八章试读，再选择单章或完整解锁。每章免费试读展示 2—3 行有意义的个性化内容，不使用模糊遮罩或截断句子；已购正文统一包含核心结论、优势天赋、潜在盲区和行动建议。

完整报告售价 ¥88，单章售价 ¥16.8。单章支付金额会抵扣完整报告，购买五章后只保留 ¥4 补全入口。已购章节可进入首页聊天继续追问，聊天顶部显示引用的报告章节并沿用每日免费额度。

报告页面延续首页的暖米白、墨色和朱砂红视觉，复用现有国学老师头像。报告是主内容，老师欢迎语、章节引导和追问卡片承担陪读作用，不引入新的古装人物形象。

用户首次点击“生成我的报告”后，页面先展示报告试读和付费入口，停留 5 秒再展示一次“免费领取完整报告”卡片。从历史报告直接进入时不触发。用户可以关闭并继续原付费流程，也可以点击绿色微信按钮进入本地模拟领取页；两种操作都会记录首访已处理，返回后不重复弹出。正式接入时只替换微信目标，不改变弹层展示规则。

## 专业排盘入口

专业排盘入口采用四列宫格，完整展示 13 个当前启用项目。视觉延续首页的暖米色、藏青文字、朱橙 / 天青点缀、淡山水和竹枝装饰；每个入口使用独立的国风线性图标，并跳转至对应的独立信息页，不使用底部弹层。

方式列表上方设置微信咨询 Banner，进入本地微信模拟页后可返回原排盘页面；右上角“排盘记录”当前为明确可见的占位入口。当前实现完成“选择方式 → 填写必要字段 → 提交排盘”的前端流程，不包含历法换算、真实排盘算法、结果页及外部服务跳转。后续按入口逐项接入算法、盘面和记录列表。
